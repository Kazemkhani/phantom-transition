The framework-free case (a plain asyncio agent with a stop button) is measured separately in `results/core-v2/asyncio-interleaving.txt`: cancelling a task does not cancel the tasks it spawned, and a barge-in after the tool's effect has landed is a phantom transition even when the tool task is cancelled.

## Configurations

- `sync-tool`: tool mutates state synchronously as soon as the call is emitted; barge-in 1.0 s into the reply.
- `inflight-tool`: tool awaits 3.0 s before mutating, so it is still executing when the barge-in lands 1.0 s into the reply.
- `late-tool`: tool call is emitted 4.0 s into the reply, after the barge-in at 1.0 s; measures whether cancellation reaches a call not yet emitted.
- `disallow-interruptions`: as sync-tool, but the tool invokes the runtime's per-tool barge-in opt-out before mutating; measures what the opt-out costs.
- `handoff-tool`: as sync-tool, but the tool also returns the runtime's agent-handoff primitive after mutating, the shape of the production transition tools; measures whether the mutation and the handoff share a fate.
